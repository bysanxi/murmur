# 池塘组件

中文 | [English](./README.md)

`@murmur.pond`（三息之间）的技术实现。这个目录是组件源码。Deskulpt 从 `index.jsx` 出发，把入口和它引用到的文件打成一个 ESM 包。没有任何文件引用的内容不会进包，包括本说明。

应用第一次启动时，会把这个目录复制到正在使用的组件目录：开发时是 `target/debug/widgets/@murmur.pond`，发布时是 `Documents/Deskulpt/widgets/@murmur.pond`。复制只发生一次。之后改的是这里的源码；运行副本更新之后，再刷新组件才会用上新代码。

## 文件

| 文件                   | 职责                                                             |
| ---------------------- | ---------------------------------------------------------------- |
| `deskulpt.widget.json` | 清单。入口是 `index.jsx`。默认尺寸按壁纸填写，层级为 `-1`。      |
| `index.jsx`            | React 宿主。管视口、那句文案，以及挂载和卸载。                   |
| `viewer.js`            | 观赏用的适配层。建立模拟、驱动帧循环，并在重新挂载时留住上一帧。 |
| `lines.js`             | 时段、气氛，以及当前语言下的句子。                               |
| `vendor/core.js`       | 鱼的身体、转向和 `PondSimulation`。挂到 `window.PondCore`。      |
| `vendor/art.js`        | 用 Canvas 2D 画锦鲤、龟、蟹、蝴蝶的精灵。挂到 `window.PondArt`。 |
| `vendor/gl.js`         | WebGL2 渲染器，失败时退回 2D。挂到 `window.PondGL`。             |
| `vendor/scene.js`      | 把生物、浮萍和天气摆到渲染器上。挂到 `window.PondScene`。        |
| `vendor/pond-data.js`  | 池塘照片，一张 JPEG data URL，放在 `window.POND_IMAGE`。         |

引擎来自 fishwallpaper，只保留观赏。投喂、声音、手绘图案、城市天气和鱼的存档都没有接上。

## 引擎素材

引擎里只有一张位图：池底画。上游用 imagegen 生成，提示词留档在上游的 `assets/ARTWORK.md`，再由 `scripts/embed.mjs` 把 JPEG 整个 base64 成一行 JS：

```js
window.POND_IMAGE = "data:image/jpeg;base64,...";
```

内联是因为 `file://` 下图片像素对 WebGL 是跨域的，`texImage2D` 会拒绝读取；data URL 才能安全上传并 `generateMipmap`。竖屏时 `fitBed()` 把整张画转 90° 铺满屏幕，所以竖屏也能装下一个完整的池塘。

荷叶、荷花和石头不是单独的素材。上游在 `scene.js` 里用一张 `FLOATERS` 表手工标注了约 120 个椭圆（`[x, y, rx, kind]`），`floatMask()` 据此画出三色遮罩：红是露出水面的部分、绿是在水底投影的部分、蓝是贴着水面留湿痕的部分。渲染时这些区域从底图里被"抠"出来，单独画在水面之上。

其余纹理全部在运行时生成：

| 类别     | 生成方式                                                                                                                                                      | 位置                                        |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| 生物贴图 | Canvas 2D 逐像素或矢量绘制                                                                                                                                    | `vendor/art.js`                             |
| 噪声纹理 | CPU 一次性生成两张 256²。一张是四通道可平铺 value noise，供云影、焦散扭曲、水珠和雪花取样；另一张是 26 个随机整数频率正弦叠加的坡度场，供微风波和太阳碎光取样 | `vendor/gl.js` 的 `noiseData` 和 `waveData` |
| 声音     | 纯 Web Audio 合成，没有音频文件（上游才有，本组件未接）                                                                                                       | 上游 `audio.js`                             |

## 贴图：生物是怎么画出来的

两套画法，按"要不要形变"分工：

- **逐像素 `ImageData`**：鱼身、龟壳。纹理要贴合曲面，还要额外输出光照通道。
- **矢量 `Path2D` 加渐变**：鳍、四肢、翅膀、蟹钳、花瓣。这些部件要独立活动，形状也规则。

鱼的局部坐标定义在 `core.js` 的 `BODY` 里：鼻尖 `+34`、尾尖 `-58`、宽 `96`、半宽 `14`，是俯视图。默认 `ppu` 为 `3.5`，贴图 336×98 px。

`fishLayers()` 在这张网格上每像素做六件事：

1. **覆盖率与法线**。`cov` 做 1 像素抗锯齿；`v = y/w`、`nz = sqrt(1-v²)` 把体宽当成圆柱，后面所有明暗都靠它。
2. **鳞片定位** `scaleAt()`。行坐标用弧长 `asin(y/w)*w`，所以鳞片在体侧自动挤密；错行排列加 `hash` 抖动；只在 3×3 邻域里找"最靠前且覆盖此点"的那片，返回 `{r, id, x, y, dx}`。
3. **花纹场** `patternFor()`。fbm 噪声加阈值，输出红斑和墨斑两个标量场；阈值每条鱼随机 ±0.06，红斑面积因此各不相同。
4. **底色**。按品种插值：黄金沿背脊走暖金，青鲢从背脊深青转到侧腹亮银，纯红从背脊深绯转到侧腹猩红。
5. **kiwa 与 sashi**。尾侧边缘按鳞片中心取样花纹场，边界天然咬在鳞片轮廓上，是锐利的 kiwa；头侧用前后两点的差值做 `smooth`，模拟白鳞一片片压进红斑，是渐隐的 sashi。这是把锦鲤品鉴术语直接落成采样策略的一处。
6. **鳞片立体感**。每片画三样：头侧压在邻居下面的阴影（pocket）、尾侧自由边的细暗线（line）、自由边内侧的受光亮带（margin）。再加每片独立的明暗抖动，以及 4% 概率的单鳞闪光。

结果是四个通道：`albedo` 是颜色和 alpha，`shade` 是静态明暗，`spec` 是静态高光，`fin` 是单独一层尾鳍。分工是关键：`albedo` 是素颜，`shade` 和 `spec` 是视角无关的预烘焙光照，随太阳和云变化的那部分留给 shader，所以换天气不需要重画鱼。

`fishSprite()` 再合成成品：手绘图案用 `source-atop` 叠上去，然后逐像素把尾鳍 alpha over 进身体，最后画矢量细节，包括鳃盖、鼻孔、须，以及四层径向渐变拼出的眼睛。

缓存分两级。`layerCache` 按 `品种:palette:seed:ppu` 缓存最贵的逐像素计算，LRU 上限 90；`viewer.js` 按 `species:palette:seed` 缓存合成好的 canvas。

其余生物遵循一条规律：**要动的用矢量拆件，要质感的用逐像素**。龟壳是另一个逐像素件，13 个盾片中心做 Voronoi 接缝，加生长环和圆顶受光；但四肢、头和尾拆成 5 个矢量部件，按划水相位分别旋转。蝴蝶、蜻蜓、蟹同样是拆件的矢量件。

上游还带着 `tests/` 目录。`core.js` 和 `art.js` 不依赖 DOM，可以用 `node --test` 直接跑，断言里甚至写进了审美判断，比如"吻部圆钝，不是尖的"、"鳞片逐片变化，不能是平的"。

## 游动：改顶点，不改贴图

贴图只画一次，是静止的"鱼皮展开图"。游动是每帧把这张皮弯到一条脊柱上，一个像素都不重画。三步：

1. **CPU 算脊柱** `updateSpine()`。前 5 段是刚体跟头走，其余 11 段只能在限角内跟随上一段走过的路径，也就是 follow-the-leader，转弯时自然甩尾。
2. **叠加行波** `fishPose()`。`lat = amp * env * sin(phase - u * 5.4)`，头部几乎不动，尾部摆幅最大。`phase` 每帧按游速推进，`amp` 每帧按推力和转弯调整，摆尾的节奏和幅度是物理算出来的，不是关键帧。输出 17 个点的 `(x, y, 法线x, 法线y)`。
3. **GPU 拼皮带**，`vendor/gl.js` 的 `fish()`。沿脊柱每点按法线两侧各出一个顶点，`u` 是身体纵坐标映射到图集的列，`v` 是横向，相邻两列连成 16×2 个三角形，全部鱼塞进一次 `drawElements`。

皮带本身是等宽的矩形，半宽恒为 `BODY.half`，鱼的轮廓、钝圆的头和收窄的尾柄全靠纹理 alpha。**UV 钉在身体坐标上，鱼皮就像一张可以随意弯曲的贴纸**，弯多少花纹都跟着走，这也是上面花纹必须按身体坐标生成的原因。

变形之后还像圆柱体受光，靠每个顶点多带的 `vLight = (横向位置, 局部半宽比, metal, gloss)`。半宽比由 `halfWidth()` 算出，场景的 `bodyLight` 负责组装；片元着色器用 `dFdx` 求出横向、构造绕体法线打方向光，鱼一转弯高光就滑过体侧。

鳍的分工：尾鳍就在鱼皮里，跟着脊柱末端一起甩；胸鳍是独立的矢量贴图，每帧按划水相位旋转后单独画。深度用 `k` 缩放加 `fog = [水色, 深度]`，越深越小、越偏青。

WebGL2 不可用时，`drawStrip2D()` 把鱼皮切成 16 段逐段 `drawImage`，是同一套思路的 Canvas 2D 版。

成本很低：每帧每条鱼在 CPU 上只算 17 个点，几何全部塞进一次绘制调用。

## 摇曳：画里的植物怎么动

抠出来的植物不是钉死在画上的。底图只提供像素；每帧场景依据椭圆、水面和天气重算每株植物的姿态，一共四层：

1. **CPU 给每株配了各自的钟。** `FLOATERS` 每个条目进场景后带上四个随机相位和 0.8–1.2 的独立速度，所以没有两株同步。摇摆是两个不同频率的正弦混成旋转 —— `turn * sin(t * 0.33 * sp + p0)` 再叠一个倍频 —— 另两个正弦混成 1.6 到 3.2 像素（乘视口缩放）的位移。幅度按种类取：大浮叶几乎不转（0.032，水把它按平），立在茎上的花苞摆得最凶（0.13），花点头（0.085），其余漂 0.075，再整体乘 `gust = 0.8 + look.wave * 0.45`，天气决定池塘呼吸的力度。这张表同时定下绘制顺序：石头先画，叶子从大到小，然后花瓣、花苞，花压最上面。
2. **雨点砸下去，弹簧收回来。** 雨滴按面积分配给某株植物，`hit()` 在落点激起水花冠，并给它的弹簧一脚 —— 花苞最经不起（3），花瓣 2，大花 1.2，叶子按大小反比（`clamp(22 / rx)`），所以小叶乱颤、大叶几乎不动，石头只溅水花不颤。之后场景对阻尼弹簧积分 `jv += (-60 * ja - 6 * jv) * dt`，各项掉到 `1e-3` 以下就清零，于是叶子颤一阵自己回到原位，不会停在偏移处。
3. **GPU 让它随波起伏。** `VS_FLOAT` 在 quad 中心四周采四次刚刚由 pass 6 写出的水面图，求出梯度，把四角按 `梯度 × push` 推开：大叶 1.8、画里的小花瓣 3.5、其余 2.6（都乘视口缩放），石头是 0 纹丝不动。同一梯度作为 `vTilt` 一路传下去，浪从底下过时，荷叶杯心里积的水会跟着滑。抠图用的那张遮罩还把植物下方的涟漪场乘成 0，波在叶边折断，而不是从叶子里穿过去。
4. **植物进了模拟。** 宽于 25px 的椭圆会变成屏幕坐标系里的圆进 `sim.obstacles`（短轴的 0.55，石头 0.95）：鱼选目标时拒绝圈内的点，转向时又被推回圈外，所以锦鲤是绕着叶子游的。落花更轻：从荷花旁边生成，缓缓漂向池心，边漂边转，活 60 到 120 秒，各画一遍影子精灵和水面精灵。

以上全部只读椭圆坐标和其后的像素：换一张床底，动画一行都不用改。

## 光影与渲染管线

光照参数是一组 `look`。`vendor/scene.js` 里有 sunny、cloudy、rain、snow 四套预设，`lookFor()` 在其上叠加雨量、雪量和夜晚，`lerpLook()` 做指数平滑，所以天气切换是渐变的。方向光固定为 `sun = [-.45, .45, .77]`，`shadowDir = [.7, .72]` 决定所有投影的偏移方向。

每帧七个 pass，顺序就是 `render()` 里的注释：

| #   | pass           | 分辨率           | 内容                                                                                                                                          |
| --- | -------------- | ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | 涟漪           | 网格不超过 900²  | `FS_DROP` 一次注入至多 24 个雨点或投喂，再在 RGBA16F 的 ping-pong FBO 上跑波动方程，固定 90Hz，带边界吸收和粘性去网格噪点，荷叶和石头挡住水波 |
| 2   | 焦散           | 1/2              | 动画 Worley 边缘网，加噪声域扭曲                                                                                                              |
| 3   | 云影           | 1/8              | 3 octave 噪声随风漂移并缓慢变形                                                                                                               |
| 4   | 阴影           | 1/2 加 mipmap    | 把精灵再画一遍，只写 alpha                                                                                                                    |
| 5   | 水下场景       | 全分辨率         | 底图 `FS_BED` 合成阴影与焦散，再画水下精灵                                                                                                    |
| 6   | 水面到最终合成 | 1/2 再到全分辨率 | 坡度与碎光，然后折射、调色、月亮、暗角                                                                                                        |
| 7   | 浮水物与空中物 | 全分辨率         | 荷叶浮出水面，然后水面物、空中物，最后发光用加法混合                                                                                          |

几个值得记的设计：

- **投影不用 shadow map**。精灵画第二遍只写 alpha，越靠近水面的影子越大越淡，`vFog.x` 控制 mipmap 模糊；底图 pass 四次采样得到软影，颜色乘 `vec3(1, .86, .72)` 模拟水先吸收红光。云一遮，阴影自动变淡变糊。
- **云影是总开关**。焦散、太阳碎光、鱼身高光、阴影深浅全部读同一张 cloud FBO，云下一起减弱并转冷灰。
- **水面**。坡度是涟漪高度差加三层微风波，按法线折射偏移采样水下场景，朝光面亮、背光面暗，再掺天空反光；太阳碎光是 `pow(N·H, 1100)` 乘上噪声块，只在晴天出现。
- **月亮是真月相**。`moonPhase()` 从已知新月推出今晚月龄，最终合成里画晨昏线半椭圆和玛瑞亚海斑，再被波纹打碎，带月光碎光和波间星点。
- **荷叶和水面是同一层空气**。浮水物的片元着色器里，雨珠当小透镜画，有暗环、向光面高光和背光面聚光；叶心积水随波倾斜，顶点着色器读水面坡度；积雪、雾、闪电和云影都重复一遍。
- **鱼的实时受光**在精灵着色器里：圆柱体法线、高光幂次随金属度变化，随云影同步减弱，与贴图里预烘焙的 `shade` 和 `spec` 相加。

最后是调色分级：饱和度、亮度、色调、雨雾、闪电和暗角。

## 打包

`vendor` 里的每个文件都是 IIFE，把接口赋给 `window`，不走 `module.exports`。Rolldown 会把 CommonJS 导出当成模块自己的导出，那样 `window` 上的全局变量不会出现。`index.jsx` 以副作用方式引入这五个文件，然后调用 `mountPond`。

Deskulpt 把 React、Emotion 和组件 API 作为运行时外部依赖提供。本组件只引入 `@deskulpt-test/react`。

## 宿主

`Pond` 的尺寸取 `window.innerWidth` 和 `window.innerHeight`，并监听 `resize`。清单里的宽高是组件保存下来的几何。画面跟着画布视口走，这样 150% 缩放下的 4K 屏不会变成写死的 3840×2160 被裁切放大。

节点是两层并列的：

- 宿主 `div` 承接 WebGL 或 2D 画布。它的透明度是 `var(--nfr-widget-bg-alpha, 1)`，由画布外壳按「背景不透明度」写上。WebGL 上下文使用 `alpha: false`，所以降低这个元素的透明度，淡去的是水面。
- 那句文案是旁边的 `<p>`。它不吃这个透明度，也不接收鼠标。

挂载用的是 `useLayoutEffect`，这样浏览器绘制前就可以把留住的上一帧接回去。效果每分钟读一次时钟，调用 `setAtmosphere` 并更换句子。语言变化时，`subscribeLanguage` 走同一条路。句子的切换是淡入淡出：新句子先停 420ms，可见的那句再用 700ms 交叉淡化。

## 观赏层

`mountPond` 造一组固定的生物，不写入存档：

- 24 条锦鲤，来自 `PondCore.createFish`
- 一群鲢鱼，来自 `createSilverCarpShoal`
- 龟、蟹、蝴蝶打开
- 名字关闭

`prefers-reduced-motion: reduce` 时用 `eco`，否则用 `high`。Eco 把设备像素比锁成 1，目标 30 帧。High 把像素比限制在 2，目标 60 帧。渲染器还有像素上限：eco 为 160 万，high 为 830 万。超过上限就缩小帧缓冲，而不是按 4K 乘像素比分配整张贴图。

池塘照片从 `window.POND_IMAGE` 加载。`PondGL.createRenderer` 先试 WebGL2，失败就克隆画布改走 2D。上下文丢失时丢掉渲染器；只要还没有 `destroy`，就再次调用 `createPond`。

每一帧推进模拟、更新场景外观、绘制并渲染。`document.hidden` 时循环停住。传给 `simulation.step` 的速度来自当前时段；eco 下这个速度再被限制在 `0.45`。

`destroy` 停掉循环，并把 WebGL 画布画到一张 2D 画布上，存在 `parkedFrame`。`preserveDrawingBuffer` 为 `true`，这次拷贝才不是空的。下一次 `mountPond` 同步放上这张快照，等新的第一帧（含精灵）画完再换掉它。所以刷新组件时，上一帧的水面还在，宿主不会空一拍。

## 时段和语言

`periodOf` 用本地小时和是否周末决定时段：

| 时段          | 时间                     |
| ------------- | ------------------------ |
| `lateNight`   | 21:00–06:00，含周末      |
| `weekend`     | 周六、周日的 06:00–21:00 |
| `morning`     | 06:00–09:00              |
| `lateMorning` | 09:00–12:00              |
| `lunch`       | 12:00–14:00              |
| `afternoon`   | 14:00–18:00              |
| `evening`     | 18:00–21:00              |

`atmosphereOf` 把时段变成 `weather`（`sunny` 或 `cloudy`）、`night` 和模拟用的 `speed`。`lineOf` 从该时段的句子里取一句。下标是当年的第几天，所以句子按天换，不按分钟换。

语言读 `localStorage["deskulpt.language"]`，只认 `zh-CN` 和 `en`，默认 `zh-CN`。`subscribeLanguage` 监听 `deskulpt:language-changed` 和 `storage`。

## 这个目录以外

拖动手柄、全屏开关、背景不透明度，以及画布是否挂在桌面图标后面，都在 Deskulpt 的画布和组件插件里。本组件只读取那个 CSS 变量，并铺满它拿到的视口。
